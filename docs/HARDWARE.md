# 机顶盒与外设

门店部署只需安卓机顶盒和外设，机顶盒承担电脑的全部营业主机职责。开发电脑仅用于编写、构建或调试软件。

| 连接 | 设备 | 当前软件支持 |
| --- | --- | --- |
| HDMI | 显示器 | Android 横屏 WebView，建议从 1280×720 或 1920×1080 开始验收 |
| USB | 键盘 | Android 标准输入，Tab/Enter 操作，Esc 关闭弹窗，F2 定位会员搜索 |
| USB | 鼠标 | Android 标准指针与点击 |
| USB HID | 扫码枪 | 模拟键盘输入，搜索框聚焦后扫描手机号或会员号，配置 Enter 后缀提交 |
| USB | 打印机 | 原生 requestPrint 接口预留，驱动和打印队列尚未实现 |

盒子需提供可用 USB Host；多个外设可通过合适的有源 USB Hub 连接。扫码枪需设置 HID 键盘模式；串口、厂商 SDK 模式需要额外适配。当前查询支持姓名、手机号及会员号，不将未知商品码自动变成消费交易。

打印机并非接上 USB 即可打印。后续需按型号确认 USB VID/PID、端点、ESC/POS 或厂商协议、中文编码、纸宽与切纸能力，再实现 Android USB 授权、传输与持久打印队列。重新打印不得重新生成财务交易；打印成功应以适配器真实结果为准。

## 实机验收

1. HDMI 图像完整，无系统缩放导致的裁切，鼠标可访问所有按钮。
2. 键盘完成新会员、开卡和消费，弹窗焦点不会跳出。
3. F2 后扫描会员号 + Enter，正确显示会员；在编辑框中扫描不应误触发扣款。
4. 拔掉网络后新增会员与交易，重启机顶盒后仍可查询。
5. 外设拔插不影响已提交交易，打印异常不得回滚账本或重复扣款。
6. 备份恢复、断电与长期稳定性通过后，再部署正式营业环境。
